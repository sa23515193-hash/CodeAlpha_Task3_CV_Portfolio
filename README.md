## 📌 Project Overview

This project was developed as part of my **CodeAlpha Frontend Development Internship — Task 3: Build Your Own Portfolio Site**.

Instead of creating a basic portfolio page, I designed and developed a **professional interactive CV portfolio** that combines the structure of a modern resume with the visual experience of a personal developer website.

The goal of this project was to create a clean, responsive and recruiter-friendly online CV where visitors can quickly understand my:

- Professional profile
- Technical skills
- Development experience
- Education
- Projects
- Certifications
- Career interests
- Contact information

The application is designed to work smoothly across **desktop, tablet and mobile devices** while maintaining a consistent visual identity.

# 🖨️ Print / Save CV

A dedicated **Print / Save CV** functionality is included.

Users can use the browser's print dialog to:

1. Open the CV portfolio.
2. Click **Print / Save CV**.
3. Select **Save as PDF**.
4. Save the portfolio as a professional PDF document.

A dedicated print stylesheet is used to simplify the interface for printing.
